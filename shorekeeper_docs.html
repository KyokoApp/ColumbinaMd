Wuthering Waves Gacha Import Tutorial

Ikuti langkah di bawah untuk mengambil link riwayat gacha / convene kamu.

Langkah 1: Buka game Wuthering Waves di PC, buka menu Convene (Gacha), lalu buka tab History.
Langkah 2 (PowerShell): Buka PowerShell di Windows dan jalankan perintah berikut: 
iwr -UseBasicParsing -Headers @{"User-Agent"="Mozilla/5.0"} https://raw.githubusercontent.com/wuwatracker/wuwatracker/c46dbadc006ed0d2c3f3a20b06b448a45475d32b/import.ps1 | iex
Langkah 3: Link Convene akan otomatis tersalin ke clipboard kamu. Masukkan URL tersebut ke parameter endpoint /api/wuwa/gacha?url=... untuk membaca pity & history gacha.
