Intuitive API

Animate faster with an easy-to-use, yet powerful animation API.

animate('.square', {
  rotate: 360,
  borderRadius: ['14px', '50%'],
  loop: true,
  ease: 'inOutExpo',
});

Enhanced transforms

Smoothly blend individual CSS transform properties with a versatile composition API. Click stage to scatter.

animate('.shape', {
  x: random(-80, 80),
  y: random(-60, 60),
  rotate: random(-180, 180),
  composition: 'blend',
});

Advanced staggering

Create stunning effects in seconds with the built-in Stagger utility function. Hover or click any dot.

createTimeline()
  .add('.dot', {
    scale: stagger([1.3, 0.7], { from: 'center' }),
    ease: 'inOutQuad',
  }, stagger(40));

Springs and draggable

Drag, flick and throw HTML elements with realistic spring physics release.

createDraggable('.circle', {
  releaseEase: createSpring({
    stiffness: 120,
    damping: 6,
  })
});

Runs like clockwork

Orchestrate animation sequences and keep callbacks in sync with the powerful Timeline API.

createTimeline()
  .add('.ticker', {
    rotate: 360,
    duration: 3000,
    loop: true,
  });
